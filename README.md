# PEP3-2026-AnalisisDeRed
Nombre y descripción: Sistema de Análisis Estadístico de Uso de Red Universitaria.

Problema: falta de análisis estadístico consolidado sobre los registros históricos de uso de la red, según la propuesta.

Objetivo y alcance: qué busca hacer el sistema y qué queda fuera de esta versión.

Funcionalidades previstas: importar y limpiar datos, calcular estadísticas y probabilidades, analizar patrones temporales y visualizar resultados.

Tecnologías: C#/.NET y la tecnología de interfaz que finalmente decidan utilizar.

Estado del proyecto: planificación, desarrollo, pruebas o finalizado, actualizado según el avance real.

Estructura del repositorio: explicación breve de las carpetas.

Instalación y ejecución: agregar instrucciones cuando exista código ejecutable.

Documentación: enlaces al documento, Gantt, presentación, requisitos y manuales.

Equipo y responsabilidades: integrantes y funciones confirmadas.

Colaboración: cómo reportar errores, asignar tareas y proponer cambios.

Privacidad y uso de datos: reglas para trabajar con registros anonimizados.
